# EvoWorld Marketing Page Kit

This folder contains a standalone Chinese marketing landing page and reusable visual assets for EvoWorld.

## Files

- `index.html` — standalone landing page structure.
- `styles.css` — page theme, responsive layout, and component styling.
- `assets/logo-mark.svg` — square brand mark suitable for favicon, app icon, and decks.
- `assets/hero-dashboard.svg` — reusable hero product mockup.
- `assets/social-share-card.svg` — 1200×630 social preview card.
- `assets/icon-metabolism.svg` — metabolism protocol icon.
- `assets/icon-gene.svg` — gene recombination icon.
- `assets/icon-legacy.svg` — legacy/specimen icon.

## Imagen / image-generation prompt pack

Use these prompts to generate raster alternatives while keeping the current page composition stable.

### Hero dashboard raster

Create a premium fantasy sci-fi Web3 game landing-page hero image for “EvoWorld”. The image should show a polished mobile-game dashboard with a cute evolved creature, vitality resource bars, gene recombination panels, lifecycle badges, and glowing blue-green/gold lighting. Mood: mysterious evolutionary world, high-end GameFi pitch deck, cinematic but clean UI. Composition: wide 16:9, large empty area on the left for Chinese headline text. Constraints: no third-party logos, no watermark, no unreadable dense text.

### Social share card raster

Create a 1200×630 Chinese social sharing card for “EvoWorld”. Headline text must read exactly: “让注意力进化成资产”. Subheadline text: “让 NFT 拥有生命”. Visual style: fantasy game interface, evolutionary gene seed, neon aqua and gold, dark premium background, cinematic lighting. Constraints: no watermark, no extra logos.

### Independent icon set raster

Create three matching square icons on transparent or removable flat chroma background: 1) metabolism flame/drop, 2) DNA gene helix, 3) legacy shield/tree. Style: premium fantasy sci-fi game UI, dark rounded tile, aqua/gold glow, crisp edges, no text, no watermark.
