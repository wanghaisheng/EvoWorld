# 11 产品路线图：MVP 到 DAO

## 路线图原则

EvoWorld 应以“先证明生命协议，再扩展完整世界”为原则。早期不要承诺大型 3D 宇宙，而要用可验证的链上生命周期、杂交、AQS 和国库回流证明核心机制成立。

## 纪元 0：原始大爆炸

目标：完成身份、资产和社区火种。

1. 发布项目宣言、白皮书摘要和合规版说明。
2. 完成 $DARWIN 基础发行方案、国库地址和权限披露。
3. 铸造 Genesis / 始祖 EvoSpecies（如始祖哥布林）。
4. 上线资产页、血统浏览器、基础博物馆和风险披露。
5. 建立 Discord/X/官网/文档中心和创作者任务。

## 纪元 1：代谢觉醒

目标：让资产真正“活起来”。

1. 上线活力、老化、休眠、标本和化石。
2. 上线基础杂交、VRF、显隐性基因和血统树。
3. 上线 $DARWIN 消耗、燃烧、土壤基金回流和公开账本。
4. 开放第一批新手任务、照料任务和博物馆展示。
5. 建立 AQS V1.0 数据看板。

## 纪元 2：社会性涌现

目标：从个体生命扩展到部落社会。

1. 上线安全区/风险区/深渊区竞技。
2. 上线基因碎片、夺基、战斗保险和 T+2 高风险延迟。
3. 上线部落、导师、灵力场和内容贡献追踪。
4. 开放智力版税、叙事编织和 Meme Patch 提案。
5. 试运行达尔文法庭和安全委员会。

## 纪元 3：意识超越

目标：开放世界规则，让社区开始定义未来。

1. 上线环境季节、领地建设、迁徙和跨物种融合。
2. 开放 UGC 基因、视觉变异、事件脚本和物种隔离协议。
3. 扩展 AQS 防刷、内容质量评估和申诉系统。
4. 逐步迁移国库、参数和内容预算到 DAO。
5. 完成核心合约复审和治理权限日落。

## 纪元 4：完全去中心化

目标：团队从开发运营者转为协议维护者。

1. 关键参数由 DAO 管理。
2. 国库预算链上透明、周期性审计。
3. 部落可独立组织领地、事件和物种发展路线。
4. 社区可在协议框架内扩展前端、游戏模式和叙事宇宙。

## MVP 优先级

第一阶段只做必须证明的闭环：Genesis NFT、$DARWIN 消耗、活力老化、杂交 VRF、标本博物馆、AQS V1、土壤基金看板。其余系统按用户验证逐步上线。
