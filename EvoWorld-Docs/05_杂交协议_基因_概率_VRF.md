# 05 杂交协议：基因、概率、VRF

## 设计目标

杂交协议是 EvoWorld 的生产与内容生成核心。它通过消耗旧资源、组合基因、引入随机突变和记录血统，让资产供给不是简单增发，而是带有成本、风险和故事的演化过程。

## 进化双轨制

EvoWorld 应区分两类进化：

1. **杂交（Hybridization / Macro Evolution）**：多个亲本组合，生成新个体，强调血统、突变和供给控制。
2. **强化（Enhancement / Micro Evolution）**：单个个体消耗资源提升属性，强调养成、专精和个体记忆。

两者必须分开设计，避免“繁殖”和“升级”混为一谈，导致经济模型失控。

## 杂交流程

基础流程建议为：

1. 选择亲本 EvoSpecies。
2. 检查亲本活力、年龄、杂交次数、亲缘距离和冷却时间。
3. 支付 $DARWIN、基因碎片或其他材料。
4. 通过 VRF 或等价可验证随机机制生成随机种子。
5. 计算显性、隐性、突变、退化和稀有组合概率。
6. 铸造后代并写入血统树。
7. 对亲本施加疲劳、寿命消耗、冷却或部分燃烧。

## 基因结构

每个 EvoSpecies 可包含：

1. **显性基因**：直接影响外观和基础属性。
2. **隐性基因**：平时不表现，但可在后代或特殊环境中显现。
3. **突变位点**：受 VRF、AQS、环境季节和材料影响。
4. **血统标签**：始祖、纪元、部落、重大事件和创作者冠名。
5. **适应度参数**：在不同领地、季节和竞技场中产生差异。

## 概率与 AQS

概率应公开、可解释、可审计。AQS 不应直接保证稀有结果，而应作为“质量乘数”影响：

1. 稀有突变的边际概率。
2. 杂交失败时的资源返还率。
3. 隐性基因显现概率。
4. 高阶基因编辑或定向配方的准入权。
5. 智力版税追踪：攻略被采用时给原创贡献者微量回流。

核心原则是：资本提供燃料，劳动提高效率，但不得承诺确定收益。

## VRF 与公开审计

杂交、突变和高价值事件应使用 VRF 或可验证随机方案。公开页面至少展示：

1. 随机种子来源。
2. 关键概率区间。
3. 消耗与燃烧比例。
4. 亲本与后代基因摘要。
5. 可复核的事件日志。

## 风控限制

为防止滥用，应设置亲缘惩罚、杂交冷却、代际衰减、最大繁殖次数、机器人检测和异常交易限制。杂交不是无限印钞，而是伴随代谢成本的基因重组。
