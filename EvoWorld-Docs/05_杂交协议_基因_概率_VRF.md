# 05 杂交协议：基因、概率、VRF

## 杂交协议的作用

杂交是 EvoWorld 的核心生产机制。玩家通过选择两个或多个 EvoSpecies，消耗 $DARWIN，并在公开概率和随机源的约束下生成新生命。杂交应同时承担资产创造、资产消耗、基因流动和叙事推进四个功能。

## 基本流程

1. 选择亲本并锁定资产。
2. 读取亲本显性、隐性、能力和历史基因。
3. 计算基础继承概率、突变概率和畸变概率。
4. 支付或锁定 $DARWIN。
5. 调用可验证随机函数（VRF）生成结果。
6. 铸造新 EvoSpecies，并记录血统链路。
7. 根据规则扣除亲本活力、增加年龄压力或触发标本化条件。

## 概率原则

杂交概率必须公开、可验证、可审计。项目方不能在后台暗改稀有率。推荐把概率拆成三层：

1. **确定性继承**：部分基础物种特征必然继承。
2. **权重型继承**：稀有基因按权重抽取。
3. **随机突变**：由环境、纪元、亲本状态和 VRF 共同决定。

## VRF 要求

VRF 用于降低黑箱抽卡争议。关键随机结果应在链上或可验证环境中产生，并向用户展示请求 ID、随机种子、结果哈希和结算时间。

## 防垄断设计

同一亲本的杂交次数越多，成本越高，活力损耗越大，畸变概率或低质量后代概率越高。顶级基因必须依赖新鲜低阶基因补充，避免少数大户永久垄断基因池。

## 叙事价值

每次杂交都应生成一段血统记录。玩家需要知道“它从哪里来、继承了什么、突变了什么、为何珍贵”。这会把抽奖行为转化为生命叙事。
