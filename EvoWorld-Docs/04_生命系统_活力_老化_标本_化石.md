# 04 生命系统：活力、老化、标本、化石

## 设计目标

生命系统是 EvoWorld 区别于静态 NFT 的核心。它通过活力、老化、休眠、标本和化石，让资产拥有时间感与代谢成本，防止无限产出、僵尸库存和单纯囤积。

## 活力值（Vitality）

活力值代表 EvoSpecies 当前生命能量。它影响：

1. 杂交成功率与突变概率。
2. 战斗表现与风险承受能力。
3. 领地采集、事件参与和奖励权重。
4. 外观表现，例如色彩、光泽、动作和生命特效。

活力可通过互动、喂养、强化、部落活动、AQS 贡献或特殊事件恢复，但恢复应消耗时间、$DARWIN 或资源，避免无成本永生。

## 老化与熵增

老化是数字生命的“荒芜税”。资产在时间流逝、频繁使用或长期闲置中都会发生状态变化：

1. **自然老化**：随时间缓慢降低活力上限或提高维护成本。
2. **战斗疲劳**：频繁竞技造成短期衰减，防止机器人高频刷收益。
3. **闲置熵增**：长期无互动的资产逐步黯淡，产出下降。
4. **环境压力**：不同纪元对特定基因产生正负影响。

老化不是惩罚用户，而是让资产有生命周期，让生态必须不断进行选择、退出和更新。

## 休眠舱（Hibernate Mode）

休眠为长期持有者提供低摩擦保护：

1. 暂停或显著减缓老化。
2. 停止收益、繁殖、竞技和大部分治理权重。
3. 唤醒时支付冷却成本或接受短期活力惩罚。
4. 长期休眠可能造成活力上限轻微衰减。

休眠机制保护真实用户，同时防止大户无成本冻结优势。

## 标本态（Specimen State）

当活力耗尽、玩家主动退休或纪元淘汰触发时，资产可进入标本态：

1. 不再常规繁殖和战斗。
2. 可展示于生态博物馆。
3. 保留血统、战绩、叙事标签和历史荣誉。
4. 可获得微量、稳定、非承诺式的历史回流或纪念权重。

标本态让死亡不等于归零，而是从生产资产转为历史资产。

## 化石态（Fossil State）

化石是更深层的封存状态，适合用于：

1. 灭绝物种的历史记录。
2. 早期纪元或重大事件资产。
3. 博物馆、展览、知识库和跨纪元叙事。
4. 特殊治理纪念或未来复兴素材。

## 生命周期闭环

EvoSpecies 的基础路径为：出生 → 成长 → 杂交/强化 → 竞技/部落 → 老化 → 休眠或标本 → 化石/遗产。玩家的策略不是让每个资产永生，而是在不同阶段决定继续投入、转化用途或体面退出。
