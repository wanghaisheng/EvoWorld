# 08 经济模型：燃烧、回流、国库、流动性

## 经济设计目标

EvoWorld 的经济模型不是简单“产出—卖出”，而是代谢式金融：每一次进化都消耗能量，每一次消耗都产生燃烧、回流和再分配，每一次资产退出都把历史转化为生态土壤。

## $DARWIN 基础原则

1. 建议采用固定总量与不增发叙事。
2. 定位为生命精华、功能燃料和治理资源。
3. 主要消耗场景包括杂交、强化、抗老化、休眠唤醒、基因编辑、竞技门票、部落注册和治理提案。
4. 不公开承诺收益、回本、价格或保底。

## 燃烧机制

$DARWIN 的消耗可拆分为：

1. **永久燃烧**：减少流通或总供应，强化稀缺与代谢感。
2. **土壤基金回流**：进入国库，用于新人补贴、罕见突变奖励、濒危物种保护、安全预算和公共事件。
3. **生态奖励池**：用于 AQS、导师、内容贡献、竞技和治理奖励。
4. **流动性与安全储备**：用于流动性管理、审计、保险和异常事件处理。

具体比例应按阶段公开，并可由 DAO 调整。

## 土壤基金（Soil Fund）

土壤基金体现“落红化泥”的循环：顶层玩家的消耗不完全消失，而是转化为生态养料。它可用于：

1. 新人首月任务补贴。
2. 高 AQS 新手的精准滴灌。
3. 濒危物种救助和纪元复兴。
4. 罕见突变、优质攻略、叙事编织和安全赏金。
5. 博物馆、标本展览和公共基础设施。

## DFEAP：动态燃料效能调节

当 $DARWIN 价格、活跃度或燃烧成本剧烈变化时，应通过动态燃料效能调节（DFEAP）避免通缩陷阱：

1. 用“能耗比”而非固定代币数量衡量关键操作成本。
2. 高 AQS 可获得一定注意力抵扣，但不得免费刷资源。
3. 土壤基金可在极端冷启动或危机时进行公开、规则化的补贴。
4. 必要时引入更小计价单位，降低新手心理门槛。

## 流动性设计

流动性应服务生态稳定，而不是制造短期拉盘叙事：

1. 公开国库地址和关键资金流。
2. 高价值操作使用延迟结算和异常监测。
3. 避免把回购、燃烧或奖池描述为收益承诺。
4. 使用日落条款限制临时护盘和紧急参数权力。

## 经济闭环

玩家消耗 $DARWIN → 部分燃烧 → 部分进入土壤基金 → 回流新人、创作者、安全和世界事件 → 产生更多真实互动 → 提高 AQS/LECR → 推动下一轮进化。
