# 13 合规框架与公开话术

## 合规原则

EvoWorld 应以娱乐、收藏、社区治理和数字生命实验为核心定位，避免被包装成投资产品。所有公开材料都应避免收益承诺、价格保证、回本周期、稳赚模型和诱导性金融话术。

## 可使用表述

1. EvoWorld 是数字生命与社区治理实验。
2. $DARWIN 用于生态内功能消耗、参与和治理。
3. EvoSpecies 是具有链上血统、状态和历史记录的数字收藏资产。
4. 杂交概率将尽可能公开、可验证、可审计。
5. 国库资金将用于生态建设、安全、活动和社区预算。
6. 用户应理解数字资产价格波动和流动性风险。

## 避免表述

1. 保证升值、保底收益、稳定分红。
2. 买入即可躺赚。
3. 官方托底价格。
4. 无风险套利。
5. 拉新返利式收益承诺。
6. 把燃烧、回购或奖池描述为证券收益。

## 风险披露

公开页面应明确提示：数字资产价格可能大幅波动；游戏规则和参数可能经治理调整；NFT 流动性不保证；合约、市场和钱包均存在风险；用户应自行评估参与能力。

## KYC 与地区限制

若涉及法币入口、抽奖、奖池、收益分配或高风险地区用户，应根据法律顾问意见设计 KYC、地理限制和活动规则。不要在未审查前面向所有司法辖区开放高敏功能。

## 内部流程

每次公开活动、代币说明、白皮书更新和营销海报发布前，应经过产品、法务、合规和社区负责人复核。合规不是削弱叙事，而是保护项目长期存在。
