# 13 合规框架与公开话术

## 合规原则

EvoWorld 应以数字生命实验、互动收藏、社区治理和娱乐体验为核心定位。evoworld.md 中的强叙事可用于内部世界观和社区文化，但公开材料必须避免收益承诺、价格保证、回本周期、证券化分红和诱导性金融话术。

## 推荐定位

1. EvoWorld 是进化型数字资产网络与数字生命实验。
2. $DARWIN 是生态内功能燃料、参与资源和治理资源。
3. EvoSpecies 是带有基因、活力、血统和历史记录的互动数字收藏资产。
4. AQS 用于衡量生态贡献，可能影响游戏内权限、声望和概率参数，但不保证经济收益。
5. 国库用于生态建设、安全、活动、补贴和公共预算，具体规则公开并可审计。

## 可使用表述

1. “资产会成长、老化、标本化，并保留历史记录。”
2. “杂交概率、VRF 和关键参数将尽可能公开、可验证、可审计。”
3. “AQS 鼓励真实贡献，包括内容、治理、照料和社区协作。”
4. “土壤基金用于生态回流，例如新人教育、安全和公共活动。”
5. “用户应理解数字资产价格波动、流动性和智能合约风险。”

## 避免表述

1. 保证升值、稳定分红、保底收益、官方托底。
2. 买入即可躺赚、稳赚不赔、无风险套利。
3. 用燃烧、回购、国库或奖池暗示证券收益。
4. 承诺固定回本周期或固定 ROI。
5. 鼓励用户借贷、梭哈或超出承受能力参与。
6. 把 AQS 描述为能保证稀有爆率或保证收入。

## 风险披露

公开页面应明确提示：数字资产价格可能大幅波动；NFT 流动性不保证；游戏规则和参数可能经治理调整；合约、钱包、市场、桥接和第三方服务均存在风险；用户应自行评估参与能力。

## KYC 与地区限制

若涉及法币入口、抽奖、奖池、代币销售、收益分配、高风险地区用户或营销空投，应根据法律顾问意见设置 KYC、地理限制、资格条款和活动规则。

## 内部发布流程

白皮书、官网、代币说明、活动海报、KOL 脚本和公告发布前，应经过产品、法务/合规、社区和安全负责人复核。合规不是削弱叙事，而是保护项目长期存在。
