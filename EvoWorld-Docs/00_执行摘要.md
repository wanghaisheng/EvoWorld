# 00 执行摘要

EvoWorld 是一个“进化型数字资产网络（Evolutionary Asset Network）”：把玩家的注意力、内容贡献、链上行为和社群协作，沉淀为可拥有、可进化、可继承、可交易并可退出的数字生命资产。

## 一句话定位

> 在 EvoWorld，注意力不再单向耗散给平台，而是凝结为有基因、有寿命、有历史、有后代的主权资产。

## 核心问题

1. **Web2 注意力耗散**：用户贡献时间、情绪、内容和社交关系，平台获得广告收入与数据资产，用户难以保留资产主权。
2. **静态 NFT 僵尸化**：许多 NFT 只有稀缺图片，没有生命周期、使用场景和持续演化理由。
3. **GameFi 经济不可持续**：若只依赖新资金和产出收益，生态会快速进入通胀、挤兑和流失。
4. **内容创作者价值外溢**：攻略、叙事、二创、社区教育通常帮助生态增长，却缺少协议级追踪与回流。

## 核心解法

1. **代谢协议（Breath / Metabolism）**：EvoSpecies 拥有活力、老化、休眠、标本和化石状态，资产必须被照料，否则熵增衰减。
2. **进化双轨制**：杂交负责“横向繁衍与基因重组”，强化负责“纵向养成与个体发育”，两者共同消耗 $DARWIN 并制造持续内容。
3. **AQS 注意力质量权重**：从链上代谢、内容布道、生态引力三个维度衡量真实贡献，让劳动、知识和影响力进入概率、资源和治理分配。
4. **标本与遗产系统**：死亡不归零，退出资产可进入博物馆，保留历史记录、血统声望与微量稳定回流。
5. **土壤基金（Soil Fund）**：把燃烧与消耗的一部分回流为新人补贴、罕见突变奖励、濒危物种救助和公共事件预算。
6. **安全免疫系统**：通过 T+2 延迟、价值诊断曲线、社交恢复、多签、审计和反女巫规则保护资产主权。
7. **部落 DAO 与达尔文法庭**：物种、领地、规则和争议逐步交给社区治理，团队从运营者过渡为协议守护者。

## 最小可行产品（MVP）

MVP 不应追求完整 3D 世界，而应先证明四件事：

1. **资产会呼吸**：活力、老化、休眠、标本状态可验证。
2. **资产能繁衍**：杂交、突变、VRF 随机性与血统记录可运行。
3. **注意力可计量**：AQS/LECR 能把真实贡献映射到概率、资源和声望。
4. **消耗能回流**：$DARWIN 燃烧、国库回流和公开账本形成代谢闭环。

## 战略判断

EvoWorld 的长期壁垒不是单个玩法，而是一套能持续解释“数字生命为何出生、成长、争斗、老去、死亡并留下遗产”的规则系统。项目应坚持资产主权、透明概率、谨慎合规和社区共创，避免把叙事退化为短期收益承诺。
