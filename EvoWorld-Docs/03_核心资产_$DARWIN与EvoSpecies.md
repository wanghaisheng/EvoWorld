# 03 核心资产：$DARWIN 与 EvoSpecies

## $DARWIN 的定位

$DARWIN 是 EvoWorld 的基础能量、交易媒介和治理入口。它不应只被理解为投机代币，而是所有生命活动的燃料：铸造、杂交、维护、竞技报名、领地建设、复活、治理提案和特殊事件都需要消耗或锁定 $DARWIN。

## $DARWIN 的主要用途

1. **生命创造**：用于铸造首代或活动限定 EvoSpecies。
2. **杂交消耗**：支付基因组合、突变抽取和新生命生成成本。
3. **生命维护**：为高价值资产补充活力，延缓老化。
4. **竞技与事件**：作为报名费、奖池燃料或风险保证金。
5. **治理权重**：参与提案、投票、参数调整和国库预算分配。
6. **安全机制**：在 T+2 延迟期内作为争议处理、回滚保护或风控缓冲的经济基础。

## EvoSpecies 的定位

EvoSpecies 是链上数字生命 NFT。每个 EvoSpecies 都应至少包含：物种类型、基因组、活力值、年龄、血统、状态、战绩、部落归属和历史事件记录。

## 基因结构

建议把基因分为四类：

1. **显性形态基因**：决定外观可见特征。
2. **隐性潜能基因**：在杂交或特定环境中显现。
3. **行为能力基因**：影响竞技、采集、繁殖、探索等玩法。
4. **历史记忆基因**：记录战斗、迁徙、灾变、部落战争等不可复制经历。

## 资产关系

$DARWIN 是流动能量，EvoSpecies 是凝固生命。前者提供代谢，后者承载故事。一个健康生态必须让二者互相需要：只有代币没有生命会变成空气，只有 NFT 没有代谢会变成死图。
