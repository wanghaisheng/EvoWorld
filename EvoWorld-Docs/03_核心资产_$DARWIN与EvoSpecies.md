# 03 核心资产：$DARWIN 与 EvoSpecies

## 资产总览

EvoWorld 的资产体系围绕四类核心对象展开：

1. **$DARWIN**：生命精华、生态燃料和治理资源。
2. **EvoSpecies**：承载基因、活力、血统和历史的数字生命 NFT。
3. **基因碎片**：杂交、强化、定向变异和高阶编辑所需的中间资源。
4. **标本/化石**：退出常规生命周期后的历史资产与博物馆资产。

## $DARWIN：生命精华

$DARWIN 是驱动 EvoWorld 熵减的基础燃料，建议采用固定总量与不增发叙事。它的主要用途包括：

1. 铸造始祖或新纪元资产。
2. 支付杂交、强化、抗老化、休眠唤醒、基因编辑和竞技门票。
3. 参与 DAO 提案、部落注册、领地建设和争议仲裁。
4. 进入燃烧、国库、奖励池和流动性调节机制。

$DARWIN 不应被公开承诺为收益凭证；它在文档中应定位为生态功能燃料与治理参与资源。

## EvoSpecies：数字生命 NFT

EvoSpecies 不是静态头像，而是可演化的生命容器。每个个体至少应包含：

1. **身份信息**：Token ID、铸造纪元、物种、稀有度、初始 DNA。
2. **基因组**：显性基因、隐性基因、突变位点、可遗传标签。
3. **生命状态**：活力、年龄、疲劳、休眠、标本、化石。
4. **行为记录**：杂交次数、强化路径、战斗结果、领地参与、事件贡献。
5. **社会关系**：血统、导师、部落、追随关系、AQS 影响力来源。

## 基因碎片

基因碎片是连接战斗、杂交和强化的关键中间物。来源可包括：

1. 杂交失败或旧资产燃烧后的回收。
2. 高风险竞技中的属性剥夺。
3. 纪元事件、领地采集、罕见突变奖励。
4. 标本或化石的历史提取。

碎片可用于定向杂交、强化突破、季节适应和稀有外观解锁。碎片系统可以提高策略深度，但必须避免过度复杂导致新手无法理解。

## 标本与化石

标本是生命资产的体面退出：停止常规战斗与繁殖，保留展示、收藏、血统声望、DAO 纪念权重和微量历史回流。化石是更深层的历史封存状态，适合承载灭绝物种、早期纪元资产和重大事件纪念。

## 资产关系

$DARWIN 提供能量，EvoSpecies 承载生命，基因碎片提供进化材料，标本/化石保存历史。四者共同形成“出生—成长—竞争—衰老—退出—遗产”的闭环。
