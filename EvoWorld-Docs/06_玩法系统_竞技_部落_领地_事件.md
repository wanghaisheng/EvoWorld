# 06 玩法系统：竞技、部落、领地、事件

## 玩法定位

EvoWorld 的玩法不是单一战斗或单一养成，而是由生命代谢、基因演化、社群组织和世界事件组成的长期循环。玩家应能根据风险偏好选择照料、繁殖、强化、竞技、创作、治理或收藏。

## 核心循环

基础循环为：获取 EvoSpecies → 提升活力与 AQS → 杂交/强化 → 参与竞技或领地 → 获得基因碎片与声望 → 加入部落 → 参与事件和治理 → 资产老化后标本化或继续进化。

## 三层竞技场

1. **安全区**：无资产损失或仅低消耗，适合新手学习与日常任务，收益较低。
2. **风险区**：存在概率性属性剥夺、碎片损失或疲劳惩罚，是中等收益主战场。
3. **深渊区**：高风险掠夺和高稀有资源产出，适合成熟玩家、部落战争和纪元事件。

竞技应强调策略与资源管理，而不是鼓励无节制赌博式下注。

## 暴力进化与属性剥夺

高阶竞技可引入“夺基”机制：胜者有概率获得败者的基因碎片或短期适应性信息。为保护用户体验，夺基必须受到保险、冷却、风险提示、T+2 延迟和新手保护限制。

## 部落系统

部落是围绕物种、策略、创作者或领地形成的社群组织。部落可执行：

1. 共享攻略、配方和导师资源。
2. 组织竞技、领地战和迁徙。
3. 提交物种叙事、基因冠名和视觉方向提案。
4. 参与 DAO 投票、预算申请和争议仲裁。
5. 建立付费或贡献门槛的私人保护场。

## 领地系统

领地提供资源、环境加成和身份归属。不同领地可影响基因适应度、碎片产出、老化速度、战斗规则和事件概率。领地不是纯地产投机物，而是承载社群活动和资源策略的玩法场景。

## 世界事件

纪元事件可包括寒潮、辐射潮、丰饶季、迁徙季、物种危机、跨物种融合和博物馆展览。事件应服务于三个目标：制造叙事、打破最优解、推动资产流动。

## 新用户 30 天路径

1. **第 1 周**：安全区体验，获得第一只 EvoSpecies，理解活力和基础消耗。
2. **第 2 周**：尝试杂交与强化，学习基因、VRF 和资源回流。
3. **第 3 周**：加入部落，参与内容、导师或低风险竞技，提高 AQS。
4. **第 4 周**：选择长期路线：进化、收藏、竞技、创作、治理或标本化。
