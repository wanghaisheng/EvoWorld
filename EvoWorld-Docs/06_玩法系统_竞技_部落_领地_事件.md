# 06 玩法系统：竞技、部落、领地、事件

## 玩法设计原则

EvoWorld 的玩法目标不是用复杂操作压倒玩家，而是让资产之间产生真实关系。竞技制造荣誉，部落制造归属，领地制造资源冲突，事件制造环境变化。

## 竞技系统

竞技可分为自动战报、策略阵容和赛季锦标赛。NFT 的基因、活力、年龄、环境适应度和历史状态共同影响结果。战斗结果应生成可分享战报，用于传播情绪价值。

竞技奖励不应只有代币，也应包括称号、徽章、血统记录、博物馆展位资格和领地声望。

## 部落系统

玩家可围绕物种、策略、语言、地区或价值观建立部落。部落拥有共享荣誉、内部租赁、联合杂交、领地建设和 DAO 子治理功能。部落是让玩家长期留存的社交容器。

## 领地系统

领地是资源与身份的结合。不同领地提供不同环境加成，例如繁殖效率、战斗适应、化石研究、标本展览或新人孵化。领地可被建设、争夺、联盟或迁徙。

## 世界事件

事件应推动生态轮动，而不是单纯发奖。事件类型包括：

1. **环境灾变**：改变基因适应度。
2. **迁徙潮**：鼓励跨部落协作。
3. **濒危保护**：补贴冷门物种。
4. **遗迹发现**：释放化石研究玩法。
5. **纪元战争**：以赛季为单位重排荣誉。

## 玩法闭环

玩家通过事件获得目标，通过竞技获得反馈，通过部落获得关系，通过领地获得战略选择，再回到杂交和资产维护。只有形成闭环，经济系统才不会孤立空转。
