# 12 冷启动与增长策略

## 增长定位

EvoWorld 的冷启动不应只靠“买币”和“冲 Mint”，而要围绕一个强叙事：别把注意力继续喂给平台，让数字劳动凝结为主权资产。增长的核心是让用户理解自己不是玩家账号，而是物种创造者、基因持有者和生态贡献者。

## 首批人群

1. **Meme 社群**：容易理解哥布林、起义、火种和传播符号。
2. **NFT 收藏者**：关注血统、稀有度、标本和历史记录。
3. **链游玩家**：理解养成、竞技、资源循环和部落协作。
4. **内容创作者/KOL**：可通过攻略、叙事、二创和导师制获得 AQS 与影响力资产化。
5. **Web3 建设者**：关注协议、治理、国库、开源和安全。

## 3 分钟起义指南

面向大众传播时，应把复杂白皮书压缩为四个钩子：

1. Web2 在消耗你的注意力，EvoWorld 让注意力凝结。
2. 始祖 NFT 是你的数字生命地契。
3. AQS 让真实贡献影响进化概率和资源分配。
4. 资产会呼吸，老去后可进入博物馆留下遗产。

## 内容驱动增长

适合冷启动的内容包括：

1. 杂交前后对比图和突变故事。
2. “我的哥布林血统”系列短文。
3. AQS 攻略、配方实验和数据榜单。
4. 标本博物馆、死亡故事和纪元编年史。
5. 部落宣言、领地地图和竞技战报。

## 创作者激励

1. 优质攻略被采纳后可获得智力版税或 AQS 加权。
2. 高质量世界观和二创可参与 Meme Patch 与基因冠名。
3. 导师带新人可获得精神精华、声望和部落权重。
4. 长图、短视频、翻译、数据看板和工具插件都应纳入贡献评估。

## 冷启动活动

1. **始祖名单**：早期贡献者获得纪念标签而非收益承诺。
2. **AQS 初始快照**：对真实内容、测试反馈和社区建设进行记录。
3. **第一批部落**：鼓励社区自建哥布林、掠食者、博物馆派、数据派等阵营。
4. **进化实验周**：公开展示 VRF、杂交、失败、突变和回流账本。
5. **博物馆开馆**：让早期死亡/退出资产成为叙事资产。

## 增长纪律

不要使用稳赚、保底、回本、官方托底、拉新返利式收益承诺。所有传播应围绕数字生命、社区共创、收藏、娱乐、治理和实验，而不是金融收益。
